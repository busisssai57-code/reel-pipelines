# MrBeast-Style Production Pipeline
## Trend Research → Scripting → Prompt Engineering → Distribution

**Version:** 1.0  
**Last Updated:** June 2026  
**Owner:** Production Director + Social Media Manager  
**Status:** Ready for Implementation

---

## 📋 EXECUTIVE OVERVIEW

This is a **scalable, high-energy production system** designed to:
- ✅ Identify trending topics 24-48 hours before saturation
- ✅ Generate hooks that stop scrolls in **first 3 seconds**
- ✅ Create prompts that yield **production-ready visual assets**
- ✅ Distribute across platforms with **platform-specific optimizations**
- ✅ Measure and iterate using **real-time engagement metrics**

**Production Cadence:** 3-5 videos per week  
**Team Structure:** 12-15 people (outlined below)  
**Timeline:** Trend → Upload: 5-7 days

---

# 🎯 TEAM STRUCTURE & ROLES

## Core Team

### 1. **Production Director** (You)
- Oversees entire pipeline end-to-end
- Final creative approval on scripts, thumbnails, CTAs
- Manages budget and resource allocation
- Sets weekly theme/direction

### 2. **Trend Research Lead**
- Monitors trending topics across YouTube, TikTok, Twitter, Reddit
- Flags opportunities in morning standup
- Validates idea before escalation

### 3. **Lead Scriptwriter**
- Writes hooks, story beats, CTAs
- Balances entertainment + engagement
- Delivers final script doc to Prompt Engineer

### 4. **Prompt Engineer**
- Converts scripts into visual/AI-generation prompts
- Tests prompt outputs (Hunyuan Video, Stable Diffusion, etc.)
- Briefs video production crew on expected visuals

### 5. **Social Media Manager** ⭐ *KEY ROLE*
- Owns all post-launch distribution
- Creates platform-specific content cuts (YouTube Shorts, TikTok, Instagram Reels)
- Drafts thumbnails, titles, captions, CTAs
- Monitors real-time engagement; adjusts strategy mid-day
- Coordinates with community team for responses/pinning

### 6. **Production Lead**
- Briefs on-set crew
- Manages B-roll, stock footage, music
- Ensures visual consistency with brand guidelines

### 7. **Video Editor**
- Assembles rough cuts from footage + AI assets
- Applies color grading, motion graphics, subtitles
- Delivers final master for publishing

### 8. **Community Manager**
- Replies to comments, pins viral comments
- Identifies themes for future content
- Reports sentiment to Social Media Manager

## ✍️ SCRIPTWRITING PROCESS

### **Step 1: Hook Workshop (1-2 hours)**
**Owner:** Lead Scriptwriter + Production Director

**Goal:** Nail the first 8-12 seconds that will stop scrolls.

**Hook Formula (Pick ONE):**

**A) Curiosity Gap Hook**
```
FORMULA: "Wait, [surprising premise]?" or "[Action] but [unexpected twist]"

EXAMPLE:
"We gave away $100,000 to FAKE MRBEAST fans — 
watch how they reacted when they found out..."
```

**B) Emotional Hook**
```
FORMULA: "I'm about to [emotional action] and I don't know if [emotional stakes]"

EXAMPLE:
"I'm about to surprise my best friend with a $1M mansion,
and I don't know if he'll actually move in..."
```

**C) Demonstration Hook**
```
FORMULA: "This is the [superlative] [thing] ever made"

EXAMPLE:
"We built the TALLEST LEGO tower in the world 
using AI-generated instructions..."
```

**D) Challenge/Competition Hook**
```
FORMULA: "[Person A] vs [Person B] in [challenge]" 
OR "[Someone] tries [extreme thing]"

EXAMPLE:
"I challenge my team to beat me in a contest where 
the prize is [insanely high stakes]..."
```

### Hook Testing Framework:
```
HOOK OPTION 1:
"[Hook text]"
Curiosity Score: 1-10 | Emotional Score: 1-10 | Shareability: 1-10
Why it works: [2 sentences]

HOOK OPTION 2:
[repeat]

HOOK OPTION 3:
[repeat]

PRODUCTION DIRECTOR PICK: [Option #]
RATIONALE: [Why this one will perform best]
```

# 🏁 FINAL NOTES

## Success Formula (Recap)

This production pipeline succeeds when:

1. **Trends are fresh** — You identify opportunities before saturation
2. **Hooks stop scrolls** — First 3 seconds grab attention hard
3. **Scripts are tight** — No dead air, pacing is relentless
4. **Visuals are stunning** — AI + stock footage looks polished
5. **Distribution is coordinated** — Same day across all platforms
6. **Community is engaged** — Comments hit 1K+ in first hour
7. **Metrics inform iteration** — Every video teaches us something

## Running This Weekly

**Monday 8 AM:** Trend standup (2-3 ideas greenlit)  
**Monday-Tuesday:** Scripting (24h turnaround)  
**Tuesday-Wednesday:** Prompt engineering + asset prep  
**Wednesday-Friday:** Production + editing (parallel if possible)  
**Friday evening:** Final QA + scheduling  
**Sunday 6 PM:** Launch across YouTube/TikTok/Instagram  
**Sunday-Monday:** Community engagement + metrics analysis  

Repeat.
